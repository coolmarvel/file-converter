## P2 — v1.4.0 사용자 확인 대기 (2026-09-21)

- **클래식 UI 체감 확인**: 12px 밀도가 고해상도 모니터에서 작게 느껴지면 `styles/tokens.ts` 의 `font.*`·`size.*` 만 한 단계 올린다(ADR-0007).
- 자체 타이틀바(frame:false)에서 창 끌기·더블클릭 최대화·Windows 스냅 동작 실기기 확인.

## P3 — 개선 후보

- **AI 배경 제거 라이선스**: @imgly/background-removal 은 AGPL-3.0 (v1.3.0 부터). 외부 배포 전 검토 — 대안 모델(MIT/Apache) 탐색 여지 (ADR-0008).
- ~~보정 확장(Compositor 잔여)~~ → **2026-09-21 해결(v1.5.0)**: 6색역·색상화·채널별 레벨/커브·자동 3모드·스포이트·필터·효과·원근·내용 인식 (ADR-0008 2차).
- **포토샵형 편집기 프로젝트**: Compositor 의 편집기 기능(레이어·마스크·선택·브러시·복구·도장·문자·도형)을 별도 Electron 앱으로 — 이름 미정, 2026-09-21 착수.
- **원근 보정 자동 모서리 찾기**: 지금은 손으로 네 모서리를 찍는다. 문서 윤곽 자동 검출(에지+사각형 근사) 검토.
- **E2E playwright 설치 주의**: devDep 가 아니라 `npm i --no-save playwright` 인데, 이후 `npm i -D …` 를 하면 지워진다 → 다시 `--no-save` 설치.

- ~~미리보기에 변환 옵션 반영~~ → **2026-07-13 해결(v1.1.3)**: 리사이즈(비율)·회전/반전·흑백 전부 실시간 반영 (세션 8-c).
- **편집 텍스트 재편집**: 저장 전 배치한 텍스트/획을 선택·이동·삭제(현재는 실행취소/페이지 지우기만).
- **형광펜 진짜 multiply**: 현재 오버레이 내부 합성(반투명 근사). pdf-lib blendMode로 페이지와 직접 multiply 검토.
- ~~PDF 문서 정리 UI 연결~~ → **2026-07-13 해결(v1.3.0)**: OptionsBar [전체 병합]+[페이지 도구] (세션 8-f).

## P4 — 장기

- **macOS 빌드(arm64/x64 dmg)**: 현재 Windows(WSL) 환경이라 미실행. 맥에서 작업 시
  `docs/guides/packaging.md`(pdf-editor에서 이식) 절차대로 — ⚠️ 내부 번들명 ASCII(`FileConverter`) 필수,
  `scripts/dist-mac.cjs` 이식 필요, bgrm-data 354MB 포함 확인.

- ~~DICOM 미리보기~~ → **2026-07-13 무의미**: DICOM 기능 전체를 제거(전용 변환기 앱으로 분리 예정, 세션 8).
- ~~JPEG 품질 옵션 노출~~ → **2026-07-13 해결(v1.1.1)**: 컨텍스트 툴바 품질 슬라이더(jpeg/webp, 10~100%).
- **DICOM 전용 변환기 프로젝트**: 사용자가 별도 앱으로 특화 개발 예정 — 시작 시점·요구사항은 사용자 결정 대기.
  이 레포의 제거 직전 DICOM 구현은 git 이력(v1.1.0, `convert/dicom.ts`)에서 회수 가능.
- **GIF 애니메이션 보존**: 현재 GIF는 첫 프레임만 변환. 애니메이션 유지 변환은 인코더 라이브러리 필요.
- **인스톨러 다이어트(v1.3.0~)**: AI 모델 354MB 전체 번들 중 — small/medium 중 하나만 남기거나 선택 다운로드로 축소 검토 (사용자: "최적화는 나중에").
- **TIFF 다중 페이지**: 현재 첫 페이지만 디코드. 다중 페이지 TIFF → 여러 이미지/PDF 검토.
- ~~git 도입 검토~~ → **2026-07-09 도입 완료**(사용자가 직접 커밋·푸시). session-log SSOT는 유지 (세션 6, writing-guide).
