# 변경 이력

인스톨러 배포 단위의 사람용 요약. 최신이 위. 개발 진행 상세는 `session-log.md` 참고.

## [1.5.0] — 2026-09-21

Compositor(MIT) 에서 **변환기에 쓸모 있는 기능을 전부** 가져왔습니다 (편집기 전용 기능은 별도 편집기 프로젝트로).

- **문서 펴기(원근 보정)·기울기** (Ctrl+Shift+P): 비스듬히 찍은 문서·영수증의 네 모서리를 찍으면 반듯한 직사각형으로.
  기울기 슬라이더로 살짝 비뚤어진 스캔을 임의 각도로 바로잡기. 파일마다 따로.
- **효과** (Ctrl+Shift+E): 외곽선·그림자·색 덮기·안쪽 그림자. **스티커 프리셋**(흰 외곽선 + 그림자) — AI 배경 제거와 함께.
- **필터** (Ctrl+Shift+F): 가우시안 블러·모션 블러·노이즈 추가·렌즈 보정.
- **내용 인식 채우기**: 캔버스 크기로 늘린 여백을 단색 대신 주변 그림으로 자연스럽게.
- **결과를 클립보드로 복사** (Ctrl+Shift+C): 저장하지 않고 다른 프로그램에 바로 붙여넣기.
- **보정 강화**: 레벨·커브를 빨강·초록·파랑 채널별로, 자동 레벨 3방식(대비·색상·중간톤 중립),
  검정/회색/흰 점 스포이트, 색조/채도를 6색 범위별로 + 색상화(한 색조로 물들이기).
- 필터·효과가 켜지면 미리보기가 **실제 결과**를 보여 줌.
- 자동 테스트: 단위 44종 + 실제 앱 E2E 41종 통과.

## [1.4.0] — 2026-09-21

- **클래식 화면으로 전면 교체** — sh-messenger·remote-assist·sh-web-editor 와 같은 옛 업무 프로그램 느낌:
  직각·1px 테두리·12px 돋움·촘촘한 컨트롤. 창 위에 **자체 타이틀바 + 메뉴 바(파일/편집/이미지/도구/보기/도움말)**,
  아래에 **상태 줄**(진행 막대·원본→출력 크기·해상도·배율). 모든 기능이 메뉴와 단축키로도 닿는다.
- **스킨 13종**(보기 → 스킨): 파랑·회색·진회색·초록·갈색 등, 앱을 다시 켜도 기억.
- 포토샵 대체 오픈소스 **Compositor(MIT)** 에서 가져온 기능:
  - **이미지 크기**(Ctrl+Alt+I): 픽셀·퍼센트·인치·센티미터, 해상도(DPI), 비율 유지, 리샘플 끄기(인쇄 크기만 변경).
    PNG·JPEG 파일에 해상도가 기록되고, 이미지→PDF 페이지 크기에도 반영.
  - **캔버스 크기**(Ctrl+Alt+C): 여백 추가·정사각형 만들기, 9방향 기준 위치, 여백 색/투명.
  - **보정**(Ctrl+M): 레벨(자동)·커브·노출·색조/채도·그레인·반전·그라데이션 맵 — 미리보기에 바로 반영.
  - **내보내기 미리보기**(JPEG·WebP): 품질을 움직이면 실제 결과와 용량(KB)을 바로 보여 줌, 투명 자리 채울 색 선택.
  - **고품질 축소**: 크게 줄여도 흐릿하거나 자글자글하지 않게 2배씩 단계 축소.
  - **자르기 강화**: 비율(1:1·4:3·16:9 …)·픽셀 수치 입력·가장자리 스냅·Shift 비율 고정·Alt 가운데 기준.
  - **AI 배경 제거 다듬기**: 가장자리를 원본 경계에 붙여 머리카락·털 표현 개선(다듬기·이동·대비 조절).
  - **안전 한도**: 너무 큰 결과(한 변 30,000px·1억 픽셀 초과)는 만들기 전에 이유와 함께 알림.
  - 미리보기 **실제 크기(100%)·단계 확대/축소·Ctrl+휠·픽셀 그리드**.
- 내부: 코드 정리(재사용 부품화·미사용 코드 제거·Prettier 정렬), 대화상자 지연 로딩, 보정 연산 메모리 절감.
  자동 테스트: 단위 30종 + 실제 앱 E2E 32종 통과.

- **진행 표시**: 오래 걸리는 작업(AI 처리, 여러 파일 변환 등)에 로딩바 표시.
- ⚠️ AI 모델 내장으로 인스톨러가 크게 커짐 (오프라인 동작 유지 목적, 사용자 승인).

## [1.1.1] — 2026-07-13

- **DICOM 변환 제거** — DICOM은 별도 전용 변환기 앱으로 특화 개발 예정. 이 앱은 PDF·이미지 변환에 집중.
  (환자 정보 폼, DICOM 대상 버튼, dcmjs 라이브러리 모두 삭제)
- **지원 포맷 확장**:
  - 입력에 **BMP · GIF · SVG · AVIF** 추가 (GIF/SVG/AVIF는 읽기 전용 — 다른 포맷으로 변환만 가능).
  - 출력에 **BMP** 추가, PDF→이미지에 **WebP** 추가.
  - **같은 포맷 → 같은 포맷 변환 허용**: JPEG를 JPEG로 고르면 크기·품질만 바꿔 다시 저장 가능.
- **변환 옵션 확장** (컨텍스트 툴바):
  - **품질 슬라이더**(JPEG/WebP, 10~100%) — 낮출수록 파일이 작아짐.
  - **회전(90° 단위) · 좌우/상하 반전 · 흑백(그레이스케일)**.
  - 출력 크기(px)는 이미지→PDF에도 적용, PDF→이미지도 크기 지정 가능.
- **미리보기 100% = 화면 폭 맞춤 고정**: 이미지·PDF가 항상 미리보기 영역 폭에 딱 맞게 표시
  (이전에는 조건에 따라 원본 픽셀 크기로 나올 수 있었음). "맞춤" 버튼 = 100% 리셋.

## [1.1.0] — 2026-07-10

- **UI 전면 개편** — 자매 앱 "PDF 편집기"와 같은 디자인 시스템(MUI) 이식. 변환 기능·동작은 그대로.
  - 우측 사이드바에 몰려 있던 변환 옵션을 **상단 툴바 + 컨텍스트 툴바**로 재배치:
    상단 툴바에서 변환 대상(PDF/PNG/JPEG/WebP/DICOM)을 고르면, 바로 아래 컨텍스트 툴바에
    그 대상에 맞는 옵션(해상도·출력 크기·환자 정보·워터마크)만 나타남.
  - 파일 목록은 **좌측 사이드바**로 이동(접기 가능), 미리보기가 본문 전체를 사용.
  - 변환 실행은 우상단 **[N개 변환 후 저장]** 버튼, 결과 안내는 하단 토스트로 표시.
  - DICOM 환자 정보는 컨텍스트 툴바의 [환자 정보] 버튼 → 팝오버 폼으로 입력(필수 누락 시 경고 표시).
  - 브랜드 색은 기존 파랑(#3b74f2) 유지, 회색조·그림자·라운드 규칙은 PDF 편집기와 동일.

## [1.0.4] — 2026-07-08 (사용자 확인 완료)

- **워터마크 켠 채 페이지 넘기면 꺼지던 문제 수정**: 워터마크 미리보기 캔버스가 확대 배율 × 윈도우 화면 배율(DPI)만큼

  확대(140%·200%)/축소(40%)와 크기 수치를 실제 브라우저에서 검증함.
- **워터마크 미리보기 표시 정상화**: 같은 폭주 버그 때문에 오버레이 캔버스가 메모리 초과로 그려지지
  못하던 것 — 수정 후 대각선/바둑판 배치·확대 상태에서 실시간 표시되는 것 확인(스크린샷 검증).
